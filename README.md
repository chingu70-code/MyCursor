# MyCursor

윈도우용 마우스 커서 커스터마이저입니다. [YoloMouse](https://store.steampowered.com/app/1283970/)에서 영감을 받았습니다.
커서 모양·색·크기를 바꾸고, 꼬리와 효과를 더하고, 게임마다 다른 커서를 자동으로 적용할 수 있습니다.

- 설치 필요 없음: `MyCursor.exe` 하나로 실행 (Windows 10/11 기본 .NET Framework 4 사용)
- 게임 파일을 건드리지 않음: 윈도우 시스템 커서 교체 또는 화면 위 오버레이 방식만 사용

## 기능

**커서 26종**
- 기본 18종: 클래식/모던/날렵한/막대 화살표, 손가락, 검, 담배, 별, 하트, 다이아몬드, 점, 링, 십자선, 십자선+점, 링+점, 과녁, 괄호 조준경, 이미지 파일(png·ico·cur·ani)
- 애니메이션 8종: 무지개 화살표, 네온 화살표, 불타는 담배, 두근 하트, 반짝 별, 로딩 스피너, 회전 조준경, 레이더 핑
- 크기, 색상, 외곽선, 그림자, 불투명도 조절

**마우스 꼬리**: 부드러운 꼬리, 점 잔상, 커서 잔상, 담배 연기 (무지개색 지원)

**효과**: 헤일로(커서 주변 링), 글로우, 클릭 파문, 화면 십자선, 돋보기

**게임별 프로필**: 게임 exe를 지정하면 그 게임이 활성화될 때 자동으로 커서가 바뀝니다.

**편의 기능**: 창 안에 커서 가두기(듀얼 모니터), 마우스 감도 전환, 윈도우 시작 시 자동 실행, 트레이 상주

## 단축키

| 단축키 | 기능 |
|---|---|
| Ctrl+Alt+F9 | 커스텀 커서 켜기 / 끄기 |
| Ctrl+Alt+C | 빠른 커서 선택 창 |
| Ctrl+Alt+F10 | 평소 커서 프로필 바꾸기 |
| Ctrl+Alt+Z | 돋보기 |
| Ctrl+Alt+L | 창 안에 커서 가두기 |
| Ctrl+Alt+S | 마우스 감도 전환 |

## 사용법

1. `MyCursor.exe` 실행
2. 왼쪽에서 프로필을 고르거나 새로 만들고, 탭에서 커서·꼬리·효과를 설정
3. 창을 닫으면 트레이에서 계속 실행됩니다. 완전히 끄려면 트레이 아이콘 → 종료 (커서가 원래대로 돌아옵니다)

**적용 방식**
- *시스템 커서 교체*: 윈도우 커서 자체를 바꿉니다. 바탕화면과 대부분의 게임에서 동작합니다.
- *오버레이*: 게임이 커서를 직접 그려서 위 방식이 안 먹힐 때 사용합니다. 꼬리·효과와 마찬가지로 창 모드 / 전체 창 모드(테두리 없음)에서 보입니다.

설정은 `%APPDATA%\MyCursor\settings.xml`에 저장됩니다.
프로그램이 비정상 종료돼 커서가 이상하게 남았다면, 다시 실행하면 자동으로 복원됩니다.

## 직접 빌드

별도 설치 없이 윈도우에 기본으로 들어 있는 C# 컴파일러로 빌드합니다.

```bat
build.bat
```

소스는 `MyCursor.cs` 한 파일입니다.
